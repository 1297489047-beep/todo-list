# 任务铃 · 待办提醒

基于 React 19 + Vite 构建的网页版待办事项提醒工具。

## 功能

- 待办创建 / 编辑 / 删除 / 完成，支持日期、时间、优先级、备注和标签
- 到点提醒：应用内通知、可选提示音，以及浏览器系统通知
- 让任务按「今日 / 本周 / 即将 / 全部 / 已完成」视图浏览
- 概览统计：已逾期、今日待办、本周待办、今日完成进度
- 搜索标题、备注或标签；按优先级、标签筛选；按时间或最近添加排序
- 数据保存在浏览器 `localStorage`

## 使用

```bash
npm install   # 首次运行
npm run dev   # 启动开发服务器
```

浏览器打开终端提示的地址（默认 http://localhost:5173）。

## 数据说明

- 待办数据保存在浏览器 `localStorage` 中，按浏览器（用户）隔离：每个打开该链接的人都有自己的独立待办列表，互相不会覆盖。
- 数据只存在各自设备/浏览器中，不随账号跨设备同步，清理浏览器数据会清空对应待办。
- 若需要“同一账号多端同步”或服务端存储，需要接入后端与用户体系。
